### 8.3 즉시 조치 권고 (상 위험도)

1. **Docker Compose DB 비밀번호**: 환경변수 패턴으로 교체 (#1)

### 8.4 향후 로드맵

1. **보안 헤더**: Next.js HSTS/CSP/X-Frame-Options 적용
2. **NestJS 버전 통일**: chat/notification/ai-service → v11 업그레이드
3. **환경변수 검증**: Joi 스키마 기반 부트스트랩 검증
4. **Docker 이미지 버전 고정**: `:latest` → 명시적 버전 태그
